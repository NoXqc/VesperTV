## VesperTV 1.0.45 (beta)

### Choose your profile at startup
- New optional **Settings > General > Startup > Launch with profiles selector**. After the splash, choose from your profiles in a frosted glass window; a short animation opens the app in the selected profile.
- Shows your profile photos, focuses the last-used profile, and supports remote, mouse and touch. Existing parental PIN protection still applies. The switch is off by default and takes effect on the next full restart.

### Sports Mode improvements (beta)
- A **Menu** gathers Home, Search, Multiview and other app shortcuts. On phones and narrow layouts, it leaves more room for leagues and games; Back from content opens the Menu first.
- On TV layouts, **Live TV** opens channel groups and a translucent channel guide inside Sports Mode. Choose a group, then a channel to watch full screen. Back returns to the guide, then groups, then sports. CH+/CH- or Page Up/Page Down move eight rows.
- **Open full Live TV** opens the regular TV screen whenever you want its complete guide and controls. Narrow and touch layouts continue opening that regular screen directly.
- Sports Mode remains an optional **beta feature**, enabled per profile in Settings > Interface. Please report remote or layout problems through Settings > Send log.

### Media Hub
- When a provider advertises a large, cached file but returns a tiny error video, VesperTV can now show **link failed at the provider** and reopen the picker without that failed option. This check applies to initial playback; provider availability still depends on your source.

### Install
Android TV, Fire Stick and phones: install the APK over your existing app, use Downloader code **1760256**, or **Settings > Check for Updates**.

Windows: download the ZIP, extract the whole folder, and run **VesperTV.exe**. Both packages are **1.0.45, build 496**.
