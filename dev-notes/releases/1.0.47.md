## VesperTV 1.0.47 (beta)

Android TV, Fire TV and Android phones · build 520

### Media Hub
- Play opens the source picker right away. Streams appear as each add-on answers; a slow or failing source shows its own status (Loading, No streams, Retry) without holding up the others.
- Stream rows show the advertised format, file size and subtitle count. The picker gear (or Media Hub > Customize > gear) sets playback preferences per profile: auto-play, preferred source and audio language, maximum quality and Prefer SDR.
- Next episode stays on the same release when the add-on provides one. The Sources drawer during playback fills in as results arrive.
- New Continue watching and Upcoming episodes rows show the episode, progress and a Resume or Next action. Progress is shared when the same title comes from different catalogs.
- Customize lets you show, hide, pin, move and rename rows. Hiding a row never disables its playback source.
- With your TMDB key, title pages add the collection, More like this and cast credits (open an actor for their movies and shows). Without a key, matching genres from your catalogs are suggested.
- Search shows results as they arrive, with a per-source filter and status.
- Subtitles supplied with a stream are all offered, and add-ons that need request headers now play.
- Fixed: on a movie page, going back up to Play now scrolls the page back to the top.

### Live TV
- Right on a live channel jumps to the last channel you watched. Press Right again to flip between the two.
- Fixed: on some boxes (Xiaomi Mi Box), live channels froze after a few minutes with no error. The player now keeps playing when another app briefly takes the sound, and reconnects when the provider's server closes the stream.
- Fixed: Recent channels could stop saving until the app restarted.

### Windows
Windows remains at 1.0.45. It has not been rebuilt or tested for these changes; this release contains an Android APK only. The existing Windows download remains available on the website and the 1.0.45 release.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
