## VesperTV 1.0.71 (beta)

Android TV, Fire TV, Android phones and **Windows** - build 905. (Linux stays at the 1.0.70 build 869 attached to this release.)

### ✨ Catch-up
- **Catch-up starts in about 2-3 seconds** on servers that were slow to build their HLS archive (some took 12 to 44 seconds). If the picture hasn't started after 4 seconds, VesperTV asks the server for the `.ts` link instead and remembers it for that playlist. Channels on a connected **Dispatcharr** ask for `.ts` straight away (it only serves that form).
- **-10 in catch-up is instant**: the last 30 seconds are kept in memory, so you no longer wait for the server each time you skip back.
- Catch-up and movies start about 0.3 seconds sooner.

### 🐞 Match frame rate
- 60 fps channels were measured as 58.8 fps, so the TV never switched to 60 Hz and the player bar said 59 FPS. The frame rate is now measured from the average, so 50 and 60 fps channels get the right mode and badge.

### ✨ Dispatcharr
- **Connect now adds the playlist for you**: after you connect, the server's playlist is added and loaded (no second step).
- A stream picked in Sources keeps the channel's format; with an **admin** login, picking a stream switches the channel on the server itself (for everyone watching it).
- Sources also works in the iPhone / Windows / Mac / Linux player, and on phones there is a **Sources** tab on the right edge of the live player.

### ✨ Tuliprox (new)
- Settings > Playlists & sources > **Tuliprox**: sign in with your Tuliprox Web UI login (or From phone). The player's **Sources** lists the providers Tuliprox merged into the channel and the one on air; picking one switches the stream on the server (an admin login is needed for now). You can also add a playlist from the server: use an existing user, or create one for this TV.

### ✨ Media Hub
- **More catalogs**: catalogs an add-on keeps off the home screen (AIOMetadata with Home switched off, like TMDB Top Rated) can be opened from a new **More catalogs** button next to the genres.
- The 5-second **Source / File size** popup shows the picked source's quality badges.
- The side menu is narrower, with **Sources** and **Servers**, and the pop-up menus no longer pick an entry on a single OK press.
- On Windows / Linux, rows work with a mouse: hover a poster for its backdrop, click to widen it, drag a row or use the arrows at its ends.

### ✨ Player
- The bottom bar has one gold focus ring on every round button (star, previous / next, restart, play / pause), and one OK press acts once.

### ✨ Live TV
- **Faster launch** (with Fast startup on): the picture comes without waiting for the splash minimum or the movie lists, and the guide data loads far quicker.
- The guide's channel column shows number, logo and name on one line.
- **Phones**: the live guide keeps the two-line channel column, and Sports Trak's title leads the league chips in one scrolling row. Launch resume opens the playing channel's group, and the full-screen resume no longer fails silently on some launches.
- **Big playlists** (50k+ channels): merged and renamed groups count their channels, launch no longer freezes while the playlist editor's changes apply, and the editor page loads much faster. The editor's **stream test** now reads the audio (for example "4K 50fps HEVC · 5.1 E-AC-3") and duplicates sort the best picture, then 5.1, first. In the player's Sources the editor's fallbacks are tagged **Fallback**.

### ⚽ Sports Trak
- **International cricket** (men's and women's: Tests, ODIs, T20Is) and the IPL, BBL, PSL, SA20, CPL and T20 Blast leagues now come from ESPN, with live scores and standings tables. A reminder set on an older cricket game is lost.

Install:
- **Android**: Downloader code **1760256**, or update from Settings > Check for updates.
- **Windows**: `VesperTV-windows-x64.zip` from this release (unzip, run `VesperTV.exe`), or Settings > Check for updates.
- **Linux** (beta, x64): `VesperTV-1.0.70-869-linux-x64.tar.gz` from this release is the 1.0.70 build (needs `libmpv2`; extract, run `./vespertv`); it doesn't have the changes above yet.
