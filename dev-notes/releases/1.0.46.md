## VesperTV 1.0.46 (beta)

Android TV, Fire TV and Android phones · build 514

### Sports Mode and Sports Trak
- First OK previews a matched game; another OK on that playing game opens full screen. Hold keeps its game menu or feed stats.
- In the Sports Mode TV layout, start with the big player beside the game feed. Browse down to the cards for the small player; changing games there keeps the cards visible. Up from the first row restores the big player.
- Matchups include available leaders, team stats, standings and injuries. Pregame teams line up with their logos, with injuries centered. Hide scores also hides result-revealing details.
- Sidebar league reorder uses Up/Down; horizontal rows use Left/Right. Moving between the sidebar and top row preserves focus. All lists every enabled league, including those off screen.
- Live TV stays inside Sports Mode: OK previews a channel in the sports player; OK again opens full screen. Right from closed-guide groups enters the page; Left from the page returns to the open panel.
- Back opens the sidebar while playback continues, then stops playback from the sidebar, then leaves the root. An open Live TV panel closes through its guide and groups first.

### Remote and profiles
- The remote Guide/EPG button opens the live guide, including the Formuler EPG key. In Sports Mode it opens the in-page panel and keeps the current game playing while you browse.
- With Launch with profiles selector enabled, leaving the TV or Sports Mode root stops playback and returns to Who's watching. Back there asks to exit.

### Multiview
- Android 1 + 3 gains Swap mode: use the arrows to rotate playing screens through the big screen without reconnecting. Sound follows the big screen; OK or Back finishes. The hold menu now scrolls and fits the TV.

### Windows
Windows remains at 1.0.45. It has not been rebuilt or tested for these changes; this release contains an Android APK only. The existing Windows download remains available on the website and the 1.0.45 release.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
