## VesperTV 1.0.49 (beta)

Android TV, Fire TV and Android phones · build 528

### Search
- Fixed: global search was slow. Typing lagged and the app stayed sluggish for a while after leaving Search. Media Hub results now arrive in a few calm steps instead of redrawing the page for every source, and matching titles is much lighter on TV boxes.

### Settings
- New: **From phone** for the TMDB key (Settings > TMDB) and for Custom posters (Settings > Media Hub > Custom posters). Scan the QR code, paste the key or poster address on your phone, then check it on the TV and press Save. Your phone and TV need to be on the same Wi-Fi.

### Sports Mode
- Fixed: after watching a channel full screen from the Live TV guide, the selector came back behind the guide and the arrows scrolled the sports page under it. It now returns to the guide.

### Windows
Windows remains at 1.0.45. It has not been rebuilt or tested for these changes; this release contains an Android APK only. The existing Windows download remains available on the website and the 1.0.45 release.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
