## VesperTV 1.0.48 (beta)

Android TV, Fire TV and Android phones · build 524

### Media Hub
- New: Settings > Media Hub > Custom posters. Paste a poster service's address with {imdb_id} (or {tmdb_id}) where the title goes, for example a service that adds ratings to posters, with your own key if it needs one. Media Hub posters then come from it everywhere: rows, Home, search and title pages. Titles without the ID keep their normal poster; leave the address empty to turn it off.
- Fixed: on title pages, the More like this and Cast and credits rows scroll steadily with the remote instead of jumping around. The page follows the row you are on, and going back up to Explore more no longer scrolls the page down.

### Windows
Windows remains at 1.0.45. It has not been rebuilt or tested for these changes; this release contains an Android APK only. The existing Windows download remains available on the website and the 1.0.45 release.

### Install
Update through Settings > Check for Updates, download app-release.apk, or use Downloader code **1760256**. Install over your existing app to keep your setup.
