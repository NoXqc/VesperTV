How the editor works

Test flight: this editor is new. Your provider's playlist is never changed, and every change can be undone, but please report anything odd (Settings > Send log on the TV).

Everything here changes only what this TV shows. Your provider's playlist is never modified, and your changes are applied again every time the playlist updates. Pick the playlist at the top, make changes, then press Save to TV (bottom right) or the save button of the tab.

Channels

Search or filter (hidden, renamed, copies, no guide, dead...). Type over a name to rename it. Tick channels, then use the bottom bar: Hide, Show, Reset name, Set logo. Fallbacks on a row: channels to play, in your order, if this one fails (from any playlist).

Groups

Rename a group by typing its new name. Merge: tick two or more groups, press Merge selected and give the new group a name (typing the same name on several groups does the same). Move groups with the arrows and hide them with the box. Press Save groups.

Duplicates & cleanup

In Rules & cleanup, tick Hide lower-quality copies: only the best copy of each channel (4K / FHD / HD) stays listed, the others become automatic fallbacks. Add rules to rename (for example remove US| ) or hide (for example PPV) many channels at once; they keep working after every update. Preview shows the effect before saving. The Duplicates tab shows which copy is kept.

Several playlists

In Playlists: use other playlists as fallback (a failing channel switches to the same channel from another provider), and Combine playlists (one lineup: a channel the first playlist already has is hidden in the others and kept as a fallback). Playlist order is the order in Playlist Manager on the TV.

Stream test (careful)

Opens each chosen stream for a few seconds to read its real quality and find dead links. Providers can block an account or your internet address after many connections in a row: test small batches (at most 60), stop any video on the TV first. Progress shows at the top of every tab.

Undo

Untick a switch, delete a rule, select channels then Show / Reset name, clear a group's new name, then save. On the TV: hold OK on a channel, Use the provider's name.

Type in a group's name box to rename it (in either list); give several groups the same name to merge them. The arrows move a group, the box hides it. Then Save groups.

Before you test

Testing opens each selected stream for a few seconds, one at a time, to read its real resolution and frame rate. Channels that really are 4K get the gold 4K tag on the TV right away. If your provider allows only 1 connection, or watches for unusual activity, your account could be suspended. The test stops by itself if the provider refuses a connection.
