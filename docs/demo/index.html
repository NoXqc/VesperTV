Try VesperTV with demo content

No provider yet? This playlist lets you try the whole app: six live channels with a TV guide, a few films and two shows, and an add-on for the Media Hub. Everything in it is free to share: Blender's open movies (Creative Commons) and silent films in the public domain.

Playlist (M3U URL)
https://vespertv.app/demo/vesper-demo.m3u
TV guide (EPG URL)
https://vespertv.app/demo/guide.xml
Media Hub add-on (optional)
https://vespertv.app/demo/addon/manifest.json

Add it

  1. In VesperTV, open Settings → Playlists & guide → Playlist Manager → Add Playlist.
  2. Choose M3U URL and enter the playlist link above. From phone lets you paste it on your phone instead of typing with the remote.
  3. Put the TV guide link in the EPG (XMLTV) URL field, give the playlist a name like "Demo", and save.
  4. For the Media Hub: Settings → Media Hub → Media Hub sources, add the add-on link.

VesperTV ships no content. It is a player for sources you already have. This demo exists so you can see how it works; it is not a channel service.
